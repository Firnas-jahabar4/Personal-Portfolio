# 🌐 Firnas M | Personal Portfolio

A responsive personal portfolio website showcasing my skills, projects, and contact information.  
Designed with a clean UI, simple navigation, and smooth scrolling — built using **HTML**, **CSS**, and **JavaScript**.

---

## 🚀 Features

- **Modern & Responsive Design** — Works perfectly on all devices (desktop, tablet, and mobile).  
- **Sidebar Navigation** — Easy access to Home, About, Skills, Projects, and Contact sections.  
- **Smooth Scrolling** — Seamless transitions between sections.  
- **Hero Section** — Highlights introduction with circular profile image.  
- **About Section** — Includes education and hobbies.  
- **Skills Section** — Lists technical and soft skills with icons.  
- **Projects Section** — Displays real-world projects with short descriptions.  
- **Contact Section** — Simple form to reach out and resume download link.  
- **Social Links** — Direct links to LinkedIn and GitHub profiles.

---

## 🛠️ Technologies Used

- **HTML5** — Structure of the website  
- **CSS3** — Styling, layout, and animations  
- **JavaScript (Vanilla)** — Scroll behavior and active link highlighting  
- **Font Awesome** — Icons for navigation and social links
